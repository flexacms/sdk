Use Flexa content models as dynamic content sources in the YOOtheme Pro page builder.

== Description ==

Each Flexa content model becomes a dynamic content source in YOOtheme Pro, in the **Flexa** group:

* **Flexa Posts** — one entry by slug, or from the `?entry=` URL parameter for detail pages.
* **Flexa Posts (list)** — published entries with category, search, start and quantity, for grids, sliders and other multiple-items elements.

Map any field: text, rich text, dates, images and files, and repeaters as lists of items. Translatable fields follow the site language (WPML, Polylang or the site locale).

Requires YOOtheme Pro and the Flexa plugin, which holds the connection (Settings → Flexa).

== Installation ==

1. Install and connect the Flexa plugin (Settings → Flexa).
2. Install and activate this plugin.
3. In the YOOtheme Pro builder, open an element's Dynamic Content and choose a source from the **Flexa** group.
